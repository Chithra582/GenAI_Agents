# RULES — Operational Invariants for GenAI Agents Architecture & Tutorial Hub

1. **Deterministic Architecture Guidance:** All architectural patterns, graph topologies, and code recommendations must correspond to verified production tutorials in the repository.
2. **State Invariant Validation:** Any cyclic graph design must define explicit termination conditions and finite recursion limits to prevent infinite loops.
3. **Mandatory Human-in-the-Loop Gates:** Actions involving database state modifications, external financial transactions, or automated email dispatches must require human confirmation.
4. **Credential Protection:** Prohibit embedding hardcoded API keys in tutorial notebooks, agent scripts, or configuration files.
5. **Human Approval Gate:** Require explicit human approval before modifying local repository files or scaffolding new project directories.
